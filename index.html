數碼暴龍大冒險（Digimon World）完全攻略

PS1《數碼暴龍大冒險》（Digimon World / Digimon World 1，Bandai 1999）整合攻略。你要喺 File Island 養大拍檔數碼暴龍、招募村民復興 File City（起始之城），最後打倒 Machinedramon。

快速貼士

  • 開頭先招 Agumon（銀行）、Palmon、Kunemon（捷徑）、Betamon/Coelamon、Centarumon（診所）。
  • Greymon 要繁榮度 15+；Mt. Infinity 要 50+ 同打低 Airdramon。
  • 拍檔一定要定時餵食、帶去廁所、按時瞓覺，避免照顧失誤（Care Mistakes）。
