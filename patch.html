🀄 繁體中文漢化補丁

粉絲製作嘅 Digimon World 1（日版 Rev 1）繁體中文漢化補丁。呢度唔提供遊戲鏡像，要用你自己嘅日版 Rev 1 碟（BIN／CUE）。

下載包入面有咩

資料夾：DigimonWorld1-Rev1 TC v1.0.2

  • DigimonWorld1-Rev1-zhHant-1.0.2.xdelta：標準 xdelta 補丁
  • DigimonWorld1-Rev1-zhHant-1.0.2.cue
  • Windows exe 工具：來源可以用原版日版 Rev1、v1.0.1 或者較早嘅 v1.0.2，會自動驗證。

要用邊個版本嘅碟？

  • 標準 .xdelta 只可以打落未改過嘅日版 Rev 1 BIN，檔名通常係 DigimonWorld (Japan) (Rev 1).bin。已經打咗舊漢化嘅 BIN 請用 Windows exe 工具。
  • 實測打得成功嘅原碟：BIN 381,162,768 bytes。
  • 說明檔寫嘅原碟 SHA-256 開頭係 44511bf9…。
  • ⚠️ 有啲標住「The Best」嘅 381,160,416 bytes 版本打唔到，會出 target window checksum mismatch。

Mac 打補丁步驟

  1. 裝 xdelta3：Terminal 打 brew install xdelta（要先裝 Homebrew）。
  2. 將原版 BIN 同補丁 .xdelta、.cue 放喺同一個資料夾。
  3. 喺嗰個資料夾執行：
    xdelta3 -d -f -s "DigimonWorld (Japan) (Rev 1).bin" DigimonWorld1-Rev1-zhHant-1.0.2.xdelta DigimonWorld1-Rev1-zhHant-1.0.2.bin
  4. 檢查：shasum -a 256 DigimonWorld1-Rev1-zhHant-1.0.2.bin 應該係
    4bc937d527bda1374121a0680cff8ac6bfc7efeb5746691cb260546ef9cdb207（大細 396,109,728 bytes；2026-10-28 實測 OK）。
  5. 輸出嘅 .bin 檔名一定要同 .cue 入面 FILE 嗰行一樣，兩個擺埋一齊。

Windows 可以直接用下載包入面嘅 exe 工具。

點樣玩

  • 先閂咗舊遊戲，再喺 OpenEmu、DuckStation 等模擬器開新嘅 .cue（唔係 .bin）。
  • 用記憶卡存檔或者開新遊戲；唔好讀舊即時存檔。
  • 漢化版用語可能同本站譯名唔同，以遊戲為準。
