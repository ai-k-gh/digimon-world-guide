🀄 繁體中文漢化補丁

粉絲製作嘅 Digimon World 1（日版 Rev 1）繁體中文漢化補丁。呢度唔提供遊戲鏡像，要用你自己嘅日版 Rev 1 碟（BIN／CUE）。

目前版本：1.0.0（初版，2026-10-25 修正版）。作者表示之後會有大更新，到時要用新補丁重新打一次。

版本內容（1.0.0）

  • 保留完整繁中排版，移除追加玩法功能。
  • 狀態頁隱藏作息、失誤、戰鬥次數、壽命、進化時間同疲勞（文字、圖標、條形框同數值）。
  • 性質、屬性、類型用原版橫排共用長框；名字框縮短。
  • HP、MP 字距改為 12 像素，修正字母黐埋。
  • 以上只係顯示調整，內部養成規則不變。

要用邊個版本嘅碟？

  • 一定要係日版 Rev 1，檔名通常係 DigimonWorld (Japan) (Rev 1).bin。
  • 實測打得成功嘅原碟：BIN 381,162,768 bytes。
  • ⚠️ 有啲標住「The Best」嘅 381,160,416 bytes 版本打唔到，會出 target window checksum mismatch。
  • ⚠️ 說明檔寫嘅來源大細（394,289,280）同 SHA-256 唔啱，唔使理，以打完之後嘅結果為準。

Mac 打補丁步驟

  1. 裝 xdelta3：Terminal 打 brew install xdelta（要先裝 Homebrew）。
  2. 將 Rev 1 嘅 zip 解壓，同補丁 .xdelta、.cue 放喺同一個資料夾。
  3. 喺嗰個資料夾執行：
    xdelta3 -d -f -s "DigimonWorld (Japan) (Rev 1).bin" DigimonWorld1-Rev1-zhHant-1.0.0.xdelta DigimonWorld1-Rev1-zhHant-1.0.0.bin
  4. 檢查：shasum -a 256 DigimonWorld1-Rev1-zhHant-1.0.0.bin 應該係
    0ef0ef5fd8223bd900277135d69027f634b7e5486caa17558dc396ef6e0fde48（大細 394,310,448 bytes）。
  5. 輸出嘅 .bin 一定要同補丁附帶嘅 DigimonWorld1-Rev1-zhHant-1.0.0.cue 擺埋一齊。

Windows 可以用補丁附帶嘅工具，或者任何支援 xdelta／VCDIFF 嘅工具，做法一樣：來源揀原版 BIN，補丁揀 .xdelta。

點樣玩

  • 喺 OpenEmu、DuckStation 等模擬器開 .cue（唔係 .bin）。
  • 要開新遊戲，或者用原版內容嘅記憶卡；唔好讀舊即時存檔。
  • 漢化版用語可能同本站譯名唔同，以遊戲為準。
